# 🕵️ 문장 탐정단: 5분 영어 문법 퀴즈

## 📌 앱 소개

**문장 탐정단**은 초등학교 6학년 학습자가 영어 문장의 **구성 성분(S·V·O·C)**과 **1~5형식**을 재미있게 확인하는 짧은 퀴즈입니다. 학생은 문장을 보고 정답을 선택한 뒤, 왜 그렇게 판단했는지 친구에게 말해 봅니다.

## 🎯 학습 목표

- 문장에서 **주어(S), 동사(V), 목적어(O), 보어(C)**를 찾을 수 있다.
- 문장 성분의 배열을 근거로 **1~5형식**을 말할 수 있다.
- 자신의 답을 간단한 말로 설명할 수 있다. 💬

## 👩‍🏫 대상 및 시간

| 항목 | 내용 |
|---|---|
| 대상 | 초등학교 6학년 |
| 선수 학습 | 영어 품사의 기본 개념 |
| 활동 시간 | 약 5분 |
| 사용 언어 | 영어 예문, 한국어 안내와 해설 |
| 준비물 | 브라우저를 사용할 수 있는 기기 |

## 🎮 진행 방법

1. **미션 시작 🚀**을 누르면 5분 타이머가 시작됩니다.
2. 앞의 4문제에서는 노란색으로 표시된 부분의 **문장 성분**을 고릅니다.
3. 뒤의 4문제에서는 문장 전체의 **형식**을 고릅니다.
4. 답을 선택하면 정답과 짧은 이유가 바로 나타납니다. ✅
5. 다음 문제로 넘어가기 전에 짝에게 **“왜 그렇게 생각했는지”** 말합니다.
6. 마지막에 점수를 확인하고, 헷갈렸던 문장을 다시 설명합니다. 🔎

## 🧩 문제 구성

| 구분 | 문항 수 | 예시 | 확인할 내용 |
|---|---:|---|---|
| 문장 성분 | 4 | `My brother is kind.` | `kind`는 주어를 설명하는 보어(C) |
| 문장 형식 | 4 | `Dad gave me a book.` | S+V+O+O인 4형식 |

형식 문제에는 **1형식부터 5형식까지**의 정답이 각각 포함됩니다. 모든 문제는 4지선다형이며, 선택 직후 해설을 볼 수 있습니다.

## ✨ 주요 기능

- ⏱️ **5분 타이머:** 시간이 끝나면 현재 점수로 활동이 마무리됩니다.
- ⭐ **실시간 점수와 진행률:** 학습자가 남은 문제를 쉽게 확인할 수 있습니다.
- 💡 **즉각적인 피드백:** 정답과 문장 분석 이유를 함께 보여 줍니다.
- 🔁 **다시 도전:** 같은 문제를 처음부터 다시 풀 수 있습니다.
- 📋 **정답 한눈에 보기:** 활동 후 8문제의 정답과 해설을 확인할 수 있습니다.
- 📱 **기기 대응:** 컴퓨터와 휴대전화 화면에서 사용할 수 있습니다.
- 🌐 **오프라인 실행:** `index.html` 파일을 브라우저에서 열면 인터넷 없이 작동합니다.

## 💡 수업 활용 팁

정답을 클릭하는 것만으로 끝내지 않고, 학생이 **“주어는 Birds, 동사는 fly, 그래서 1형식!”**처럼 근거를 소리 내어 말하도록 유도해 주세요. 짝 활동으로 진행하면 짧은 시간 안에 여러 학생의 설명을 들을 수 있습니다.

> **성공 기준:** 학생이 문장 성분을 찾고, 그 배열을 근거로 문장의 형식을 말한다. 🏆
